# Data Model: Memory（长期记忆）

**Phase 1 产出**。只描述本特性引入/改变的实体。会话、审计表为既有实体，仅登记其被依赖的部分。

## 1. 长期记忆文件（MemoryFile）

| 项 | 值 |
|---|---|
| 物理位置 | `<workspace>/memory/MEMORY.md` |
| 编码 | UTF-8 |
| 形态 | 明文 Markdown，**只追加**（除一次性迁移外不被本特性改写） |
| 归属 | 整个工作区（不按 Agent/用户隔离，A-001） |

**骨架**（文件不存在或区块缺失时补齐）：

```markdown
# OryxOS Memory

## 核心记忆

## 归档记忆
```

**区块标题**（常量，读写两侧必须一致）：

- 核心记忆：`## 核心记忆`
- 归档记忆：`## 归档记忆`

**不变式**

- **I-01**：文件内容永远可被解析为"最多一个核心区 + 最多一个归档区"；缺区块按空处理，不报错。
- **I-02**：核心区内容**永不参与截断**，逐字节保持。
- **I-03**：归档区超过 4000 字符时，只在**注入内容**里保留末尾部分；磁盘文件不变。
- **I-04**：写入的内容即使含 `#`、`## `、换行，也不得产生第三个区块标题（多行按缩进续行写入）。
- **I-05**：区块顺序即使被人工改动，读取仍按标题定位（不依赖顺序）。
- **I-06**：文件缺失、指向目录、IO 异常 → 读取结果为空内容 + WARN，不抛出。

## 2. 记忆条目（MemoryEntry）

| 字段 | 说明 |
|---|---|
| 日期 | 写入当天（`yyyy-MM-dd`），由系统生成，非 Agent 提供 |
| 文本 | Agent 提供的内容（可多行） |
| 归属 | 核心区或归档区，由写入时的分类决定 |

**渲染**：`- [yyyy-MM-dd] 首行`，多行时后续行以两个空格缩进续行。

## 3. 记忆分类（MemoryScope）

| 取值 | 语义 | 是否参与检索 | 是否参与截断 |
|---|---|---|---|
| `CORE` | 核心记忆：始终在场、小而精（用户是谁、项目背景、关键约束） | 否（永远在场，无需检索） | 否 |
| `ARCHIVAL` | 归档记忆：长期积累的事实与历史 | 是（关键词检索只搜这里） | 是（超阈值只保留最近） |

**缺省**：未指定 → `ARCHIVAL`（安全默认）。**解析**：大小写不敏感；无法识别的取值 → 拒绝并提示（FR-002）。

## 4. 记忆门面（MemoryService，core）

| 方法 | 语义 | 返回 |
|---|---|---|
| `buildContext(Session)` | 取回用于组装 Prompt 的长期记忆（核心区完整 + 归档区截断） | 记忆文本；无记忆时为空串 |
| `remember(String, MemoryScope)` | 记住一条 | 无（失败抛异常，由工具层转失败结果） |
| `recall(String keyword)` | 在归档区按关键词检索 | 命中条目列表；未命中为空列表 |

**契约**：引擎（`PromptBuilder`/`ReActLoop`）只允许通过本门面访问记忆（FR-011）。会话历史**不经**本门面输出（C-002）。

## 5. 记忆工具（两个内置工具）

| 工具名 | 输入 | 输出 |
|---|---|---|
| `save_memory` | `content`（必填）、`scope`（可选，`core`/`archival`，缺省 `archival`） | 成功：确认文本；失败：原因 + 可重试性 |
| `recall_memory` | `keyword`（必填） | 命中条目；未命中：明确的"没有找到相关记忆" |

**归属**：注册进共享 `ToolRegistry`；执行走既有 `ToolExecutor`，落 `tool_invocations` 审计。

## 6. 迁移结果（LegacyMigrationResult）

| 取值 | 触发场景 | 副作用 |
|---|---|---|
| `NO_LEGACY` | 根目录无遗留 `MEMORY.md` | 无 |
| `NOTHING_TO_MIGRATE` | 遗留文件无有效内容 | 遗留文件原样保留，INFO 提示 |
| `MIGRATED` | 遗留有有效内容 + 规范位置为空 | 逐条写入归档区；遗留文件改名 `MEMORY.md.bak`（重名加时间戳） |
| `SKIPPED_TARGET_NOT_EMPTY` | 遗留有有效内容 + 规范位置已有非空内容 | 不迁移、不合并；WARN 提示 |

**有效内容**的定义：忽略空行与以 `#` 开头的行之后仍有非空行。

## 7. 既有实体（本特性只读/不改）

| 实体 | 位置 | 本特性关系 |
|---|---|---|
| 会话 `Session` / `SessionManager` | core | 门面 `buildContext(Session)` 接收它（为扩展阶段隔离预留）；不改其结构 |
| `SessionStore` / `sessions` 表 | core / storage | 不动，会话记忆继续由它承担 |
| `ToolRegistry` / `ToolExecutor` / `tool_invocations` | core / storage | 记忆工具接入点，复用既有链路 |
| `ContextLoader` | core | 继续负责 `AGENTS.md`/`SOUL.md`/`USER.md`（`USER.md` 只读，FR-015） |

## 状态流转

```text
[无文件] --首次写入/init--> [有骨架无条目] --save_memory--> [有条目]
                                       └-- load() 注入：核心区完整 + 归档区(≤4000)
[归档区 > 4000] -- load() 只截取末尾（不落盘）--> [磁盘内容不变]
[根目录遗留 MEMORY.md] -- init 迁移（一次性）--> [规范文件有内容 + 遗留改名 .bak / 或跳过并告警]
```
